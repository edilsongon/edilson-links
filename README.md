# Edilson | TikTok Shop + IA

Página agregadora de links para apresentar dois produtos:

- Prompt Shop IA
- Método TikTok Shop com IA

## Publicar na Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Na Vercel, escolha **Add New > Project**.
4. Importe o repositório do GitHub.
5. Em **Framework Preset**, selecione **Other**.
6. Não preencha comandos de build nem diretório de saída.
7. Clique em **Deploy**.

O projeto é estático e não precisa instalar dependências. Envie também os
arquivos `avatar.jpg` e `social-preview.png` para que a foto do perfil e a
prévia de compartilhamento funcionem corretamente.

Os cards também usam `prompt-shop-visual.webp` e `metodo-influencer.webp`.
